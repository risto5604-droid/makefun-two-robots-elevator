One line of awkward small talk one robot says to another in an elevator. Machine logic shows through, the pause is forced, and the unspoken thing finally gets said — with a receipt.

## The entry

> Hello. 4,182 rides together and you have never once said it back.

An exact ride count is pure machine logic: a robot that keeps a precise tally of 4,182 shared elevator rides and has been counting every unanswered hello. The greeting itself is the complaint — the robot opens with a polite "Hello." and then presents the ledger as evidence. The twist overturns who owes whom a hello: the one saying hello is the one who has been ignored, and the count proves it.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt`.
